## 💡 工作原理

### 创作者模式

```
1. 查询该创作者已有的最新笔记
2. 获取 API 返回的笔记列表（按时间倒序）
3. 从新到旧遍历:
   - 发现新笔记 → 爬取
   - 遇到已存在 → stop_count++
   - stop_count >= 3 → 停止遍历
```

### 存储支持

| 存储类型 | 增量方式 |
|---------|---------|
| **DB** | 查询 `xhs_note` 表 |
| **JSON** | 扫描 JSON 文件 |
| **CSV** | 读取 CSV 文件 |

## ❓ 常见问题

### Q: 需要数据库迁移吗？

**A: 不需要！** V2 版本直接从现有数据源获取增量信息。

### Q: JSON 存储可以用吗？

**A: 可以！** 完美支持 JSON、CSV 等所有存储类型。

### Q: 会遗漏内容吗？

**A: 不会！** 连续 3 条已存在才停止，避免误判。

### Q: 已经爬过数据了怎么办？

**A: 没问题！** 系统会自动从已有数据中找到最新位置，继续爬取新内容。

## 🎓 设计理念

> **"数据本身就包含增量信息，为什么要额外存储？"**

- 如果用 DB 存储，最新数据在 `xhs_note` 表
- 如果用 JSON 存储，最新数据在 JSON 文件
- 如果用 CSV 存储，最新数据在 CSV 文件

**直接查询现有数据，无需额外建表！**

## 🔧 配置说明

```python
# config/base_config.py

# 启用增量爬取
ENABLE_INCREMENTAL_CRAWL = True

# 早停阈值（连续N条已存在就停止）

# 存储类型（自动检测）
SAVE_DATA_OPTION = "json"  # db, json, csv, excel
```
