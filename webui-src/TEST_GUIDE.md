## 🐛 常见问题排查

### Q: 为什么我输入创作者ID没有看到标签？
**A**: 标签效果**只在 Search Mode 的关键词输入**时显示。Creator Mode 使用的是普通的多行文本框，不显示标签。

### Q: 如何测试标签删除功能？
**A**: 
1. 必须在 **Search Mode**
2. 在"关键词"输入：`111,222,333`
3. 看到标签后，点击 × 按钮

### Q: 输入框没有变化？
**A**: 确保：
1. 已经切换到对应的爬取类型
2. 页面已经加载完成（检查浏览器控制台是否有错误）
3. 如果使用开发模式，确保 `npm run dev` 正在运行

### Q: 样式不对？
**A**: 
1. 确保安装了所有依赖：`npm install`
2. 确保 Tailwind CSS 正常工作
3. 检查浏览器控制台是否有 CSS 加载错误
