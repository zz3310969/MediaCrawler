### 2. 🏷️ **标签输入功能**

#### 特性
- ✅ **回车添加**：输入后按回车，自动添加标签并清空输入框
- ✅ **单独删除**：点击标签的 × 按钮删除
- ✅ **颜色区分**：
  - 关键词：🔵 青色（cyan）
  - 帖子ID：🟠 橙色（orange）
  - 创作者ID：🟣 紫色（purple）
- ✅ **长文本截断**：URL超过30字符自动截断

#### 交互流程
```
输入 → Enter → 清空 → 标签出现 → 点击× → 删除标签
```
