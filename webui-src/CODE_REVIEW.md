## 🔧 需要优化的地方

### 1. 🎯 **工具函数应该统一管理**

**问题**：
- `formatFileSize`、`formatDate` 等工具函数散落在组件中
- `extractCategory` 业务逻辑也在组件中

**优化**：
- 提取到 `lib/utils.ts` 或 `lib/formatters.ts`
- 便于复用和测试

---

### 2. 📦 **类型定义应该独立**

**问题**：
- 所有类型定义都在 `api/crawler.ts` 中
- 类型和 API 混在一起

**优化**：
- 创建 `types/api.ts` 存放 API 相关类型
- 创建 `types/crawler.ts` 存放业务类型

---

### 3. 🎨 **App.tsx 组件太大，Props 太多**

**问题**：
- App.tsx 有 200+ 行代码
- 子组件接收 10+ 个 props（Prop Drilling）
- 配置状态管理混乱

**优化**：
- 使用自定义 Hook 管理爬虫配置
- 使用 Context 共享状态
- 拆分 Header、ConfigSection 等子组件

---

### 4. ⚠️ **错误处理不够友好**

**问题**：
```typescript
onError: (error: Error) => {
  alert('启动失败: ' + error.message)  // ❌ alert 太简陋
}
```

**优化**：
- 使用 Toast 通知（优雅的提示）
- 添加错误边界（Error Boundary）
- 统一错误处理机制

---

### 5. 🔄 **缺少加载状态**

**问题**：
- 平台列表、配置选项加载时没有 loading 状态
- 用户可能看到空的下拉框，不知道在加载

**优化**：
- 添加 Skeleton 加载占位
- 添加 Loading 指示器

---

### 6. 🎯 **缺少日志过滤功能**

**问题**：
- 所有级别的日志混在一起
- 无法只查看错误或成功日志

**优化**：
- 添加日志级别过滤器
- 添加日志搜索功能

---

### 7. 📝 **常量应该提取**

**问题**：
```typescript
refetchInterval: 1000,  // 魔法数字
reconnectInterval: 3000,  // 魔法数字
```

**优化**：
- 创建 `lib/constants.ts`
- 统一管理常量

---

### 8. 🚀 **性能优化机会**

**问题**：
- 配置变化时整个组件重渲染
- 一些计算可以 memoize

**优化**：
- 使用 `useMemo` 缓存计算结果
- 使用 `useCallback` 稳定函数引用
- 使用 `React.memo` 优化子组件

---

### 9. 💾 **配置持久化**

**问题**：
- 用户每次刷新都要重新配置参数
- 没有保存常用配置

**优化**：
- 使用 localStorage 保存配置
- 添加配置预设功能

---

### 10. 📊 **数据统计缺失**

**问题**：
- 数据管理弹窗只展示文件
- 缺少统计图表

**优化**：
- 添加数据统计卡片
- 使用 Recharts 展示图表

---
